# ❤️ Heart 1.0

Портативное устройство для получения текстовых сообщений и изображений через Интернет.

---

## 📖 О проекте

Heart 1.0 — компактное устройство на базе **ESP12F**, позволяющее получать текстовые сообщения и изображения через Интернет. Отправка сообщений осуществляется через веб-интерфейс, а дополнительные параметры можно настроить через встроенный локальный веб-сервер.

---

## 🏗️ Архитектура

Проект использует **клиент-серверную архитектуру**.

- **Сервер:** PHP
- **Клиент:** ESP12F
- **Прошивка:** C++

```text
          ┌─────────────┐
          │ PHP Server  │
          └──────┬──────┘
                 │ Internet
                 │
          ┌──────▼──────┐
          │   ESP12F    │
          └──────┬──────┘
                 │
          OLED-дисплей
```

---

## ✨ Возможности

### 📝 Получение текстовых сообщений

Устройство способно принимать текстовые сообщения через Интернет и отображать их на встроенном OLED-дисплее.

### 🖼️ Получение изображений

Помимо текста поддерживается передача и отображение изображений.

### ⚙️ Настройка устройства

Через локальный веб-сервер можно:

- добавлять Wi-Fi сети;
- настраивать параметры подключения;
- изменять параметры мигания светодиодов;
- выполнять другие настройки устройства.
